# QuickRing

Готовые версии QuickRing для Windows и Mac: **[скачать приложение](https://github.com/kanderyabl/QuickRing-Releases/releases)**.

Для работы приложения нужен ключ доступа, выданный владельцем QuickRing. API-ключи для AI настраиваются отдельно.

## Установка

- **Windows x64:** скачайте `QuickRing-Setup-*.exe` из последнего выпуска для Windows и запустите установщик. ZIP — переносная версия без установки и автообновления.
- **Mac Apple Silicon:** скачайте `QuickRing-*-AppleSilicon.dmg` из последнего выпуска для Mac, откройте его и перенесите QuickRing в «Программы». Требуется macOS 13 или новее; стеклянное оформление — macOS 26 или новее. Intel Mac не поддерживается этой сборкой.

Подпись Mac-приложения локальная (ad-hoc), нотариализации Apple пока нет. Windows-установщик пока без сертификата подписи издателя.

## Обновления

Начиная с Windows 0.11.0 и Mac 1.6.0 приложение получает обновления из этого репозитория. Более старую версию нужно один раз обновить вручную.

- Windows: установите приложение через Setup.exe; проверка и перезапуск доступны в настройках → «Обновления».
- Mac: меню QuickRing → «Проверить обновления…» или настройки → «Обновления». Вы сами выбираете момент установки и перезапуска. Архив и лента обновлений проверяются по цифровой подписи.

Настройки и лицензия сохраняются. Служебные выпуски `windows-stable` и `macos-stable` предназначены для механизма обновления, а не для ручной установки.

В репозитории публикуются только готовые файлы и информация для пользователей. Исходный код приложения хранится отдельно в закрытом репозитории. Стандартные ссылки GitHub «Source code» содержат только материалы этого публичного репозитория.
